# Asset Directory

This directory contains visuals, diagrams, and UI previews for the project documentation.

| Filename | Purpose | Current Format |
| :--- | :--- | :--- |
| `hero_banner.svg` | Hero banner displayed at the top of the README. | Scalable SVG |
| `ui_reader_studio.svg` | Preview of the Medium/Notion reading experience and typography tools. | Scalable SVG (replaceable by PNG) |
| `ui_live_stepper.svg` | Preview of the multi-agent execution pipeline with SSE telemetry. | Scalable SVG (replaceable by PNG) |
| `ui_quality_audit.svg` | Preview of the fact-check audit breakdown and anti-hallucination score. | Scalable SVG (replaceable by PNG) |

To replace any visual with an actual screenshot captured from the live application at `http://localhost:5173`, save the screenshot as a PNG with the corresponding base filename (e.g., `ui_reader_studio.png`) and update the file extension in `README.md`.
